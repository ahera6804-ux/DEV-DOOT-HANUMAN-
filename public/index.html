Privacy and safety

Do not enter Aadhaar numbers, OTPs, bank details or unnecessary medical information. Upload a person's photo only with permission. This pilot saves data on the computer running the server.

Location is only requested after you press the button.

Voice help

Press Start voice input and allow microphone access. If voice input is unavailable, on Windows press Win + H to use Windows voice typing, then speak into the help description.

Submitting does not automatically assign a helper or notify emergency services.

What is and isn't live

Requests, local tracking, provider registration, reporting and coordinator review are implemented for testing. Automatic emergency dispatch, SMS/push notifications, online payments, verified background checks, official live Kumbh feeds, and cloud database backups are not connected. Status can be checked using the request tracker; browser alerts are not guaranteed. Do not treat this pilot as a replacement for official emergency services.
